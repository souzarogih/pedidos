# .specs/

Cada mudança relevante no projeto é descrita aqui por uma spec própria, contendo:

- **Contexto**: por que a mudança é necessária.
- **Tarefa**: o que deve ser feito, de forma objetiva.
- **Regras**: restrições específicas da tarefa, além das já definidas em `AGENTS.md`.
- **Definição de pronto**: critérios que indicam que a tarefa está completa (ex.: testes específicos passando, comportamento observável).

Esta pasta **não** entra automaticamente no contexto do agente. Ela só deve ser lida quando o agente for explicitamente instruído a consultar uma spec específica.
